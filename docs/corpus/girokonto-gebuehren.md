# Girokonto — Gebühren und Leistungen

Das Girokonto Komfort der Musterbank kostet 4,90 € pro Monat.
Im Preis enthalten sind: kostenlose SEPA-Überweisungen im Online-Banking,
eine Debitkarte, kostenlose Bargeldabhebungen an allen Automaten der
Musterbank-Gruppe.

Kontoauszüge sind im Online-Banking kostenlos. Papierauszüge per Post
kosten 1,50 € pro Auszug. Die Kontoauflösung ist jederzeit kostenlos möglich.
