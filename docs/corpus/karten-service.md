# Kartenservice — Debitkarte

Verlust oder Diebstahl: Karte sofort sperren über den zentralen Sperr-Notruf
116 116 (aus dem Ausland: +49 116 116) oder im Online-Banking unter
"Karten > Karte sperren".

Eine Ersatzkarte (Debitkarte) kostet 10,00 € und wird innerhalb von
5 Bankarbeitstagen per Post zugestellt. Die zugehörige PIN kommt aus
Sicherheitsgründen in einem separaten Brief.
